Kenapa Harus di-Upgrade? 🤔

1. Handling Error (Kondisi If)

Jika bot tidak menemukan jawaban, dia tidak akan "diam" saja, tapi akan bilang "Maaf, data tidak ditemukan". Ini membuat bot terasa lebih pintar!

2. Loop (Selamanya)

Bot tidak akan berhenti setelah satu pertanyaan. Dia akan terus menunggu pertanyaan barumu!

Langkah Upgrade:

  1. Bungkus semua program di dalam Forever.
  2. Buat variabel baru bernama topic.
  3. Gunakan Set Variable untuk menampung hasil Wikipedia.
  4. Cek jika topic = (kosong), maka tampilkan pesan maaf.
  5. Jika tidak kosong, baru tampilkan hasilnya!
