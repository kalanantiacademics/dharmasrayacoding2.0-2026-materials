Hari Ini Kita Belajar... 🚀

🟠 1. Blok Repeat

Meringkas kode manual menggunakan blok oranye [repeat].

🔄 2. Forever

Menggunakan [Forever] agar karakter mengejar kursor mouse secara permanen..

❓ 3. Interaction

Menambahkan logika [If on edge, bounce] agar karakter tetap di panggung.

Tujuan: Membuat kode lebih rapi dan cepat! ✨

Blok Control Oranye 🟠

Kita pelajari kode untuk mengulang sesuatu! Supaya program Scratch kita lebih sederhana dan mudah dibaca.

forever

Misi Persiapan Hari Ini 🚀


👉 BUKA SCRATCH DI SINI 👈

Klik tombol di atas untuk membuka web Scratch di tab baru.
Setelah terbuka, klik Create atau New Project.

Langkah 1: Mencari Panggung (Backdrop) 🖼️

  • 1
    Klik ikon "Choose a Backdrop" di pojok kanan bawah.
  • 2
    Cari dan pilih satu Backdrop
  • 3
    Klik tab "Backdrops" di kiri atas untuk melihat Backdrop yang sudah dipilih.

Perhatikan gambar berikut untuk mencari Backdrop 🌄

Langkah 2: Menambahkan Karakter (Sprite) 🚶‍➡️

💡Perhatikan gambar berikut untuk menambahkan Sprite

  • 1
    Hapus Kucing Scratch (klik ikon tempat sampah).
  • 2
    Klik "Choose a Sprite", cari dengan keyword "Animal".
  • 3
    Sesuaikan nama karakter dengan Ubah namanya di kotak Sprite Name.
