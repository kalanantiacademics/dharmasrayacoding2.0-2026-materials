Webcam vs Mouse Pointer ⚖️

📹👋

Versi Webcam

Balon pop karena gerakan tangan terbaca oleh kamera.

🖱️❌

Versi Mouse

Balon pop karena Cross mengikuti mouse dan menyentuh balon.

Game yang mirip bisa dibuat dengan input berbeda. Cara bermainnya berubah, tetapi logic pop balloon-nya tetap sama: jika tersentuh, balon hilang.

Cara Kerja Balloon Popper Mouse 🖱️🎈

🖱️
✕
🎈

Sprite Cross akan selalu mengikuti posisi mouse.

Saat Cross menyentuh Balloon, balon akan hide, pindah ke posisi acak, lalu show lagi.

Jadi pemain bisa “pop” balon dengan mengarahkan mouse ke balon.

Input → Process → Output 🔄

🖱️

Input

⚙️

Process

🎈💥

Output

Balon hilang, pindah random, lalu muncul lagi.

Kita tidak memakai kamera di sesi ini. Semua kontrol dilakukan dengan mouse.

Langkah 1: Balon Muncul dan Bergerak 🎈

Langkah ini sama seperti sesi sebelumnya. Buat balon show, lalu glide to random position. Agar tidak selalu sama, gunakan set size dengan angka acak.

Langkah 2: Tambahkan Sprite Cross ❌

Sprite baru: Cross

Buat sprite berbentuk X / cross warna hitam. Sprite ini akan bergerak mengikuti mouse pointer.

when green flag clicked
forever
point towards mouse-pointer
Pastikan nama sprite-nya mudah dikenali, misalnya Cross.

Langkah 3: Balon Pop Saat Menyentuh Cross 💥

Tambahan di sprite Balloon:

Tambahkan script untuk mengecek apakah balon menyentuh sprite Cross. Jika iya, balon akan hilang, pindah random, lalu muncul lagi.

Kunci logic-nya adalah if touching Cross? Jadi balon hanya pop saat benar-benar tersentuh oleh Cross.
