Project Structure: 3 Sprites 🧱

🏠

Room

Mendeteksi ucapan di dalam forever, lalu menentukan command dan broadcast.

🌬️

Fan

Menerima broadcast fan on/off lalu switch costume.

💡

Lamp

Menerima broadcast lamp on/off lalu switch costume.

Room adalah “controller”. Fan dan Lamp adalah “device” yang mengikuti command dari controller.

Sprite 1: Room Controller 🏠

🏠🎙️
Fungsi: mendengar voice command dari user.
Logic: jika teks ucapan cocok dengan command, Room mengirim broadcast.
Command: turn on/off the lamp, turn on/off the fan.
Gunakan bahasa Inggris saat testing agar sesuai script.

Room Code: Voice Command Logic 👀

Room mengecek ucapan di dalam forever, lalu broadcast command yang sesuai. Voice Recognition hanya mendeteksi Bahasa Inggris

Room Code: Big Picture 🧠

when green flag clicked
forever
listen and convert speech to text
if text = turn on the lamp
broadcast lamp on
broadcast fan off / fan on / lamp off
Intinya: Room membaca suara, mengubahnya menjadi teks, lalu mengirim pesan ke sprite lain menggunakan broadcast.

Sprite 2: Fan 🌬️

🌬️
Fungsi: menunjukkan kipas menyala atau mati.
Jika menerima broadcast fan on: switch costume ke fan on.
Jika menerima broadcast fan off: switch costume ke fan off.

Fan Code 🌬️

Fan tidak mendengar suara langsung. Fan hanya merespons broadcast dari Room.

Sprite 3: Lamp 💡

💡
Fungsi: menunjukkan lampu menyala atau mati.
Jika menerima broadcast lamp on: switch costume ke lamp on.
Jika menerima broadcast lamp off: switch costume ke lamp off.

Lamp Code 💡

Logic Lamp mirip Fan: tunggu broadcast, lalu ubah costume.
