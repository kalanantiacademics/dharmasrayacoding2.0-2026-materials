Camera Setup & Data Safety

📷

Klik Start Camera untuk cek kamera.

Allow camera: izinkan browser jika muncul permission.
Privacy: gunakan benda, bukan wajah atau informasi pribadi.
Lighting: pastikan objek cukup terang dan terlihat jelas.
Kalau kamera belum bisa dibuka, tetap ikuti teacher dan gunakan contoh bersama.

Step 1: Define Classes

✏️

Class 1

Rename menjadi Pencil.

📘

Class 2

Rename menjadi Book.

🧴

Class 3

Rename menjadi Bottle.

Class name harus konsisten, karena class menjadi label output model.

Step 2: Collect Training Images

Target Data

Ambil sekitar 20–30 contoh per class jika memungkinkan.

Variation: ubah angle, jarak, dan posisi objek.
Balance: jumlah gambar setiap class sebaiknya mirip.
Clean label: jangan masukkan gambar botol ke class Pencil.
Dataset yang rapi membuat model lebih mudah diuji dan diperbaiki.

Dataset Checklist

Setiap class punya contoh gambar.
Objek terlihat jelas di kamera.
Gambar tidak semuanya sama persis.
Jumlah data antarclass cukup seimbang.
Tidak ada label yang salah.
Siap klik Train Model.

Step 3: Train Model

🧠⚡
Training = model mempelajari pola visual dari dataset.
Model = hasil training yang bisa dipakai untuk prediction.
Wait: jangan test sebelum proses training selesai.
Training bukan magic. Hasil model sangat dipengaruhi kualitas data yang kamu berikan.

Error Analysis: Why Did It Fail?

📚

Data Too Small

Contoh gambar terlalu sedikit untuk pola yang stabil.

🧬

Low Variation

Dataset hanya mengajarkan satu bentuk kondisi.

🏷️

Wrong Label

Ada contoh yang masuk ke class yang salah.

🎯

Ambiguous Object

Objek terlalu mirip, terlalu kecil, atau tidak jelas.
