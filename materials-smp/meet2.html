Alamat di Dunia Scratch 🏠

🏘️

Alamat Manusia

Kita menggunakan nama jalan, nomor rumah, dan kota untuk menemukan tempat.

➔
🔢

Alamat Sprite

Scratch menggunakan Koordinat (X, Y) untuk menentukan posisi pasti di layar.

"Koordinat adalah Alamat Rahasia para Sprite!"

Eksplorasi Koordinat 📍

X+ X- Y+ Y-
X: 0, Y: 0
🚁

Coba Klik!

Klik di mana saja pada area putih untuk melihat Drone berpindah tempat.

Drone akan menyebutkan koordinat persisnya!

  • ↔️ X: Kiri (-) & Kanan (+)
  • ↕️ Y: Bawah (-) & Atas (+)

Kenapa Harus Koordinat? 🤔

🏫 Sekolah

🏥 RS

MASUK KE SCRATCH 🚀

Butuh Starter Project? 🛠️

Langkah:

  1. Buka link starter project berikut:
    BUKA STARTER PROJECT 🚀
  2. Klik tombol Remix di kanan atas.
  3. Sekarang semua aset sudah ada di dalam editor kamu!

Langkah 1: Siapkan Aset 🤖

Robot Sprite

Pilih atau gambar karakter Robot-mu.

5 Rumah Tujuan

Gunakan sprite Home Button, duplicate jadi 5, ubah warna & namanya agar unik.

Langkah 2: Pilih Backdrop 🖼️

🌆

Pilih Latar Belakang

Cari backdrop yang kamu suka (misal: Blue Sky, Night City, atau Farm) dan sesuaikan dengan tema Drone-mu.

Langkah 3: Program Robot ⚙️

1

Spawn Logic

Awali posisi drone dengan blok Go to X: Y:

2

Delivery Logic

Susun urutan Glide ke koordinat rumah.

3

Return Logic

Pastikan drone kembali ke markas di akhir kode.
