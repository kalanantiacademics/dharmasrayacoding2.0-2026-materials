Blok Conditional 🟠

if then

If - Then

Hanya ada 1 pilihan aksi jika kondisi terpenuhi.

if then
else

If - Then - Else

Ada aksi alternatif jika kondisi TIDAK terpenuhi.

Blok Sensing 🔵

touching (mouse-pointer)?

Mendeteksi jika sprite menyentuh sesuatu (sprite lain, pinggir layar, atau mouse).

touching color ?

Mendeteksi jika sprite menyentuh warna tertentu di stage.

key (space) pressed?

Mendeteksi jika tombol tertentu di keyboard ditekan.

💡 Blok sensing berbentuk segienam (hexagon) karena ia adalah sebuah pertanyaan (Benar/Salah).

Cara Menggabungkannya 🤝

🧩
if touching (Food)? then
change size by (20)

Masukkan blok Sensing ke dalam lubang segienam di blok If-Then.
Lalu masukkan aksi yang ingin dilakukan di dalam "mulut" blok If tersebut.

Langkah 2: Program Player 👩‍💼

Sprite: Player Female

1

Animasi Kaki

Masukkan blok Next Costume di dalam Forever. Tambahkan Wait (0.1) secs agar pergantian kostum terlihat alami seperti orang berjalan sungguhan.

2

Arah Gerak

Gunakan Point towards (mouse) dalam loop agar selalu menghadap kursor. Wajib tambah Set rotation style (left-right) di awal agar tidak berputar 360 derajat.

3

Logika Cerdas

Gunakan If Touching. Pilih nama sprite makanan di sensornya. Jika Healthy Food: Ubah size (-10). Jika Junk Food: Ubah size (+50) secara instan!

Langkah 3: Program Makanan 🍏🍔

Gerak Acak & Kecepatan

Gunakan blok Glide (1) secs to (random position).

💡 **Tantangan**: Gunakan operator Pick Random (0.5) to (3) pada kolom detik agar kecepatan makanan berbeda-beda dan sulit ditebak!

Interaksi "Makan"

Gunakan If touching (Player Female).
Jika kena tabrak, makanan harus Hide (menghilang), Wait beberapa detik, lalu Show (muncul) kembali di tempat lain.

⚠️ PENTING: Logika di atas harus ada di SEMUA sprite makanan (Apple, Pizza, Broccoli, Fries)!
