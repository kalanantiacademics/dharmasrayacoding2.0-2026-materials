No Webcam? No Problem! 📁

Klik untuk download folder ZIP berisi kumpulan foto dataset untuk project kita:

RED DATASET 🔴 GREEN DATASET 🟢 BLUE DATASET 🔵

Foto-foto ini akan menjadi Dataset kita. Upload semua foto ini ke label masing-masing di ML4K,
lalu kita akan melatih model AI menggunakan foto-foto tersebut!

Masukkan Dataset 📸📁

  • Gunakan Webcam untuk foto benda berwarna di sekitarmu.
  • ATAU gunakan tombol Upload untuk memasukkan file ZIP tadi.
  • Minimal 15 foto per label agar AI makin pintar!
