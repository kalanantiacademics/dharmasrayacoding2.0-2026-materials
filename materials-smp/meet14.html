Step 1: Scratch Improvement 🛠️

Mari periksa kembali program kita:

  • Pastikan laser tidak "nyangkut" di tepi layar.
  • Atur ukuran botol agar tidak terlalu besar/kecil.
  • Gunakan blok go to front layer untuk laser.

Step 2: Botol Pecah! 🍾💥

🍾 Sprite: Bottle

Pasang blok ini di sprite Bottle untuk menampilkan bottle di stage:

  • Gunakan blok broadcast new bottle location.
  • Gunakan wait dengan random number
  • Spawn new bottle setiap beberapa detik sekali

Menambah Skor 📈💯

🎯 Sprite: Hit

Pasang blok ini di sprite Hit. Jangan lupa buat variable Score terlebih dahulu!

  1. Klik Variables -> Make a Variable.
  2. Beri nama Score.
  3. Gunakan blok change Score by 1 saat menerima broadcast "explode".

Step 3: Tantangan 30 Detik ⏱️

🖼️ Backdrop / Stage

Program Timer ini sebaiknya diletakkan di Stage agar rapi:

  • Buat variable Timer.
  • Set Timer ke 30 di awal game.
  • Kurangi Timer setiap 1 detik.
  • Stop All saat Timer habis!
