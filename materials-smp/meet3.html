Cek Aset & Kostum 📦

**Daftar Sprite**: Kamu akan melihat ada banyak sprite Neko (kucing).

**Kostum**: Setiap kucing punya minimal 2 kostum: Pose normal & Papan Deskripsi.

Step 1: Atur Kondisi Awal 🚩

when clicked
set size to 50%
switch costume to neko3 ▼

Fungsi Kode:

  • Agar saat bendera hijau diklik, semua kucing **MENYUSUT** (50%) supaya tidak menutupi layar.
  • Memastikan kostum kembali ke **POSE NORMAL**.

Step 2: Interaksi Klik 🖱️

when this sprite clicked
go to front ▼ layer
start sound Pop ▼
set size to 100%
switch costume to neko3-desc ▼
wait 3 seconds
set size to 50%
switch costume to neko3 ▼

Fungsi Kode:

  1. **Go to front**: Agar papan deskripsi tidak tertutup kucing lain.
  2. **Sound**: Memberikan feedback suara "Pop!".
  3. **Set size 100%**: Memperbesar tampilan agar biodata terbaca.
  4. **Wait 3 sec**: Menunggu siswa selesai membaca.
  5. **Reset**: Kembali kecil dan ke kostum semula.
