Sprite 1: Player 🎧

Fungsi: music player utama yang bertanya lagu apa yang ingin dicari.
Variables: SongTitle, Artist, Album, Playing.
Logic: ask → search for answer → set variables → play preview.

Player Code: Big Picture 🧱

when green flag clicked
set SongTitle / Artist / Album to empty
set Playing to No
ask [What to play?] and wait
search for (answer)
set variables from iTunes result
play preview
Intinya: user memberi keyword. iTunes extension mencari lagu. Scratch mengambil title, artist, album, lalu menampilkan data itu lewat variable di stage.

Player Code: Follow the Image 👀

Perhatikan urutan dari atas ke bawah: reset variables → ask → search → set data → playing.

Sprite 2: Disk 💿

Fungsi: memberi animasi disk berputar.
Kunci logic: cek variable Playing.
Jika Playing = Yes: disk terus turn 2.

Disk Code 💿

Disk tidak mencari lagu. Disk hanya membaca status Playing.

Sprite 3: Bongo Cat 🐱

Fungsi: dekorasi animasi project.
Costume: ganti costume berulang seperti GIF.
Trigger: animasi aktif saat Playing = Yes.

Bongo Cat Code 🐱

Logic-nya mirip Disk: baca variable Playing, lalu animasi berjalan.
