Langkah 1: Program Spaceship 🛰️

Logika Utama:

  • 🚀 IF Key Space Pressed: Karakter bergerak naik dengan Change Y.
  • 💥 IF Touching Meteor: Game berhenti (Stop All).
  • 📉 IF Y Position < -170: Game berhenti karena jatuh.
  • Gravity: Terus kurangi Y secara perlahan agar Spaceship jatuh jika tidak ditekan.

Langkah 2: Program Meteor ☄️

Meteor Berulang:

  • ⬅️ Motion: Bergerak ke kiri dengan Change X by (-10).
  • 🔄 IF X position < -240: Meteor kembali ke posisi paling kanan (X=240).
  • 🎲 Random Y: Gunakan Pick Random agar Meteor muncul di ketinggian berbeda.
  • ♻️ Forever Loop: Ulangi proses ini selamanya.
